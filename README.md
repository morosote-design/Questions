# Curso Interactivo de Inglés: Las Preguntas con "How..." 🚀

Sitio web educativo, moderno y 100% responsivo para aprender todas las estructuras y usos de las preguntas con **"How"** en inglés (*How much, How many, How far, How long, How often, How old, How tall, etc.*).

## 🌟 Características

1. **Pantalla de bienvenida multi-idioma**:
   - Tarjetas idénticas a la interfaz moderna con opciones para:
     - 🇪🇸 **ES** (Español / Recomendado)
     - 🇺🇸 **US** (English)
     - 🇧🇷 **BR** (Português - Brasil)
     - 🇰🇷 **KR** (한국어 - Korean)
     - 🇨🇳 **CN** (中文 - Mandarin)
     - 🇯🇵 **JP** (日本語 - Japanese)
     - 🇮🇳 **IN** (മലയാളം - Malayalam)
2. **Estructura modular limpia**:
   - `index.html`: Base general y pantalla de bienvenida.
   - `css/style.css`: Estilos oscuros elegantes con fuentes tipográficas universales.
   - `js/translations.js`: Diccionario con todas las explicaciones y traducciones para cada idioma.
   - `js/exercises.js`: 20 ejercicios interactivos con autocorrección.
   - `js/test.js`: Examen evaluativo de 10 preguntas con situaciones reales y feedback inmediato.
   - `js/app.js`: Lógica de navegación y cambio de vistas/idiomas.
3. **Listo para GitHub Pages**:
   - Funciona sin necesidad de Node.js ni servidores backend. Solo súbelo a un repositorio y activa GitHub Pages.

## 🚀 Cómo publicarlo en GitHub Pages

1. Crea un nuevo repositorio en GitHub (por ejemplo, `curso-ingles-how`).
2. Sube todos los archivos respetando las carpetas (`index.html`, `css/`, `js/`).
3. Ve a **Settings** -> **Pages**.
4. En **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
5. Haz clic en **Save**. ¡Tu curso estará online en segundos!
