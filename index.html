2. Cómo construir la pregunta

La estructura básica depende del tipo de verbo que utilices en la oración:

Con verbo to be (am, is, are, was, were)

How + adjetivo/adverbio + am/is/are + sujeto?

Ejemplo: How old are you? / How tall is she?

Con verbos de acción auxiliares (do / does / did)

How + adjetivo/adverbio + do/does/did + sujeto + verbo base?

Ejemplo: How often do you study? / How much does it cost?

Con verbos modales (can, could, will, should)

How + adjetivo/adverbio + modal + sujeto + verbo base?

Ejemplo: How fast can you run? / How far should we walk?
